# Claude Code スターターキット

このフォルダをVS Codeで開いて、左側のClaudeアイコンをクリックしてください。Claudeが案内します。

## 起動方法

1. VS Codeを開く
2. 「ファイル」→「フォルダーを開く」→ このフォルダを選択
3. 左側のサイドバーにある **Claudeアイコン** をクリック
4. チャット欄に「はじめます」と送る

## このキットで学べること

1. 環境確認（Node.js / Claude Codeのインストール）
2. CLAUDE.md の概念（Claudeへの指示書）
3. セキュリティ（機密ファイルの扱い方）
4. Gitの基本（変更履歴の管理）
5. 次のステップ（スキル / MCP）

困ったら `docs/` フォルダのトラブルシュートも参照してください。
