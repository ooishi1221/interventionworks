## Phase 1: 構築（環境確認）

### 目的
Node.jsとClaude Codeが正しく動く状態かチェックする。

### 手順（ユーザーに実行してもらうコマンドと、結果に応じた分岐）

**Step 1-A: Node.jsバージョン確認**

ユーザーに `node --version` を実行してもらう。

- `v18.x.x` 以上 → 「OK！次に進みます」
- `v16.x.x` 以下 → 「バージョンが古いです。`docs/node-troubleshoot.md` を見てアップデートしてください」と案内
- コマンド自体が見つからない → 「Node.jsがインストールされていません。`docs/node-troubleshoot.md` を見てインストールしてください」と案内

**Step 1-B: Claude Codeバージョン確認**

ユーザーに `claude --version` を実行してもらう。

- バージョン番号が表示された → 「インストール済みです！」
- エラーが出た → 以下を案内する：

```
npm install -g @anthropic-ai/claude-code
```

Windowsで権限エラーが出た場合：PowerShellを「管理者として実行」してから同じコマンドを実行するよう伝える。

**Step 1-C: 認証確認**

「VS Codeの左側にClaudeアイコンが表示されていて、今このチャットができているなら認証済みです！
もし「Sign in」ボタンが表示されている場合は `docs/auth-troubleshoot.md` を案内する。」

全Step完了したら：「環境確認OK！ステップ2に進みましょう」

## Phase 3: 保存の前に（セキュリティ）

### 目的
機密情報の取り扱いを習慣として身につけさせる。これを飛ばさない。

### 案内する内容

---

「**ここが一番大事なところです。**

Claude Codeはフォルダの中のファイルを読みます。
だから、**絶対に貼ってはいけないもの**があります：

- パスワード
- APIキー（システムへのアクセス権限）
- お客様の個人情報・顧客リスト
- 契約書・社外秘文書

これらが書かれたファイルをClaudeに見せると、チャット履歴に残ります。

**2つの守り方を覚えてください：**

**① .gitignore（ジット・イグノア）**
バージョン管理システムに保存しないファイルを指定するファイルです。
このフォルダにある `.gitignore` を開いてみてください。
`.env` や `*.key` が書いてあります。これが機密ファイルの除外設定です。

**② .claudeignore（クロード・イグノア）**
Claudeに読ませないファイルを指定できます。
このフォルダにある `.claudeignore` を開いてみてください。

**覚えておくルール：**
- `secrets/` フォルダに機密ファイルをまとめる
- このフォルダには `.gitignore` と `.claudeignore` 両方に `secrets/` が入っている
- パスワードは絶対にチャットに貼らない

---

**Vibe-Guard という便利なツールもあります。**
機密情報が誤ってファイルに含まれていないかスキャンしてくれます：

```
npx vibe-guard
```

プロジェクトが本格的になってきたら使ってみてください。」

## Phase 4: 保存（Git / GitHub）

### 目的
Gitとは何か、なぜ.gitignoreが重要かをセキュリティと連携して理解させる。

### 案内する内容

---

「**Git（ジット）は変更履歴を管理するツールです。**

「昨日のバージョンに戻したい」「誰がいつ何を変えたか確認したい」という時に使います。
GitHubはGitの履歴をインターネット上に保管する場所です。

**まず試してみましょう：**

新しいフォルダを作って、そこでGitを始める手順です。

```
# フォルダを作る（名前は何でもOK）
mkdir my-first-project
cd my-first-project

# Gitを始める
git init

# CLAUDE.mdを作る（Claudeへの指示書）
# （ここで何か書いてみてください）

# 状態を確認する
git status

# 全ファイルを追加する
git add .

# 最初のコミット（セーブポイント）を作る
git commit -m "最初のコミット"
```

**⚠️ 大事な注意：**
`git add .` をする前に `git status` で何が追加されるか必ず確認してください。
機密ファイルが含まれていたら、`.gitignore` に追加してから `git add .` をやり直します。

Windowsでgitが使えない場合は、Git for Windowsをインストールしてください：
https://git-scm.com/download/win」
