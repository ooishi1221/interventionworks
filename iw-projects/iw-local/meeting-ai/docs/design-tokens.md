# MAI デザイントークン（正本 v1 — 2026-07-05 アンナ）

> R3.3 UI磨きで制定。以後の UI 変更はこのトークンに従う。原則: **装飾を足すのではなく、面の高さ（エレベーション）差と余白のリズムだけで序列を作る**。コンテンツ（文字起こし本文）が主役、chrome は消える。

## 背景3層（エレベーション）

| 層 | 色 | 用途 |
|---|---|---|
| L0 | `#0a0a0c` | 画面背景 |
| L1 | `#17171a` | カード・タブバー・入力カプセル |
| L2 | `#1f1f23` | さらに浮く要素（回答カード等） |

## テキスト4階調

| 階調 | 色 | 用途 |
|---|---|---|
| Primary | `#f2f2f4` | 本文・見出し |
| Secondary | `#9a9aa2` | 時刻・ラベル・質問文 |
| Tertiary | `#6c6c76` | キャプション・ヒント・プレビュー |
| Placeholder | `#4a4a52` | placeholder / disabled |

## アクセント

- Blue: `#3b7cf6`（バッジ背景 `#1c2c42`）
- Amber（付箋）: `#f5b942`（付箋カード背景 `#231c10`）
- Danger: **`#ef4444` 一本**（エラーバナー背景 `#3a1414`）
- 境界線: 全箇所 `#1e1e22` に統一（線でなく階調差で区切る）

## スケール

- 余白: 4 / 8 / 12 / 16 / 24 / 32（6, 10, 14 は使わない）
- 角丸: 8（chip）/ 12（input）/ 14（カード）/ 20〜24（pill）/ 円（録音ボタン）
- タイポ: ヘッダー 17/700/ls-0.4 ・ 本文 16/400/lh24 ・ キャプション 12/500/lh16 ・ 小メタ 13/400/lh18 ・ バッジ数字 12/600/tabular-nums

## 原則

- 影より階調。shadow は録音ボタン等ごく少数に絞る
- glass morphism・グラデーション・過剰角丸は禁止
- タッチターゲット 44pt 以上
- 「同席感」は装飾でなく、時刻・付箋・回答が時系列に静かに積み上がる構造が担う
- 📌付箋の異物感は消しすぎない（「あ、お願いした」の実感）

コンポーネント別の適用値は R3.3 実装（App.tsx styles）が実体。変更時はこのファイルの原則に照らす。
