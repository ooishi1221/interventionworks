# リアルタイムAI議事録アシスタント PRD Lite & 仕様書
Real-time AI Minutes Assistant - Lightweight PRD & Design Specification

Googleのプロダクト開発思想（ユーザーフォーカス、高速なプロトタイピング、機能のモジュール化、マテリアル・デザインの原則）に基づく軽量版PRD。

---

## 1. PRD Lite

### 解決する課題

既存の議事録ツールは「会議終了後」の振り返りに終始しており、議論の最中に「文脈（過去のプロジェクト知識）を踏まえたリアルタイムの高度な壁打ち・質問」を行うことができない。

### ユーザーストーリー

- **音声認識**: アプリを起動して録音ボタンを押すだけで、発話や周囲の議論が2〜3秒のラグで即座にタイムラインへテキスト化される。
- **文脈付きQ&A**: 会議の途中で確認したい仕様や論点が発生した時、質問を入力するだけで、それまでの会議ログと事前に読み込ませたプロジェクト固有メモリーの双方を掛け合わせた最適な回答をClaudeから即座に（ストリーミングで）得られる。

### 機能優先度

| 優先度 | 機能 | スコープ |
|---|---|---|
| P0 | リアルタイム音声配信と文字起こし | ブラウザから3〜5秒の音声チャンクをストリーム送信し、Gemini APIでテキスト化 |
| P0 | ハイブリッド文脈Q&A | 会議テキストバッファ＋固定のプロジェクトメモリー(Markdown)をClaude Sonnetへ一括投入、回答をストリーミング返却 |
| P0 | 1分ごとのバッチ要約 | バックエンド側で1分ごとにGeminiを呼び出し、タイムライン要約を生成・画面更新 |
| P1 | 複数話者識別 | プロトタイプでは単一タイムライン、P1へ |
| P1 | 前提知識ファイルの動的アップロード | プロトタイプではサーバー配置の固定ファイル参照 |
| P2 | 認証・永続化・チーム共有 | 本番開発フェーズで実装 |

### 成功指標

- 音声発話から画面表示まで **3.5秒以内**
- プロジェクト固有知識を無視したハルシネーションが発生しないこと

## 2. User Journey & Interaction Map

### Happy Path

1. WebアプリにアクセスS
2. 「録音開始」ボタンをワンタップ
3. 左パネルに2〜3秒おきに発話内容がタイピングアニメーション付きで追加
4. 1分後、上部の「同期要約エリア」に最初の概要が自動生成
5. 右側チャット入力欄に質問 → Claude Sonnetが会議ログ＋プロジェクトメモリーを踏まえてストリーミング回答

### Edge Cases

- **ネットワーク瞬断**: 送信失敗時に最大3回リトライ、失敗時に「⚠️ 接続再試行中...」バッジ表示
- **無音状態**: RMS値が閾値を下回るチャンクはAPIに投げず破棄
- **空の質問送信**: シェイク・エフェクトで拒否、APIリクエスト発生させない

## 3. UI Skeleton & Component Design

### Core Layout

Google Material 3のダッシュボード・グリッドに準拠。左右 50:50 の2カラム固定分割、左右独立スクロール。

### Components

- **IconButton (FABスタイル)**: 直径56dp円形ボタン、タッチターゲット最小48×48dp
- **TimelineCard**: タイムスタンプ + ソース(Gemini) + テキスト本文を構造化
- **StreamingChatBox**: Border-radius 24pxのテキストエリア、Enter送信 / Shift+Enter改行

### Data Schema

```json
{
  "id": "tl_001",
  "timestamp": "14:02:15",
  "speaker": "Transcript_Chunk_01",
  "text": "..."
}
```

### Accessibility

- コントラスト比: WCAG 2.1 AA基準 4.5:1 以上（ダークモード含む）
- 文字起こし本文: 16px / line-height 1.5

## 検証に使える手持ち機材

- **PLAUD AIレコーダー**: 文字起こし API あり（Claude API との公式連携対応）。P0の音声→テキスト部分をブラウザ独自実装なしで検証できる。
- **Google Pixel 9**: Gemini Nano 搭載。リアルタイム音声処理のネイティブ実機テスト基盤。

→ P0 の「リアルタイム音声配信と文字起こし」はブラウザ実装を後回しにして、PLAUD / Pixel 9 で先に文字起こし精度・レイテンシを検証できる。

---

## 技術構成（IW 実装方針）

- **文字起こし・要約**: Gemini Flash（常時稼働、コスト最適化）
- **文脈Q&A**: Claude Sonnet（裕司の質問時のみ起動）
- **コスト目安**: 1時間 60〜100円
- **置き場所**: `iw-projects/iw-local/meeting-ai/`（GnH と並列、データのみ連携）
- **GnH との連携**: 会議終了後に自動でカルテ追記

## Phase 2 イケメン機能（候補）

- スライド生成（Marp / Reveal.js）→「解決イメージです」と画面共有
- UI モック作成（会話から即生成）
- コスト・納期試算（発話から数字を拾って自動計算）
- 見積もり計算（その場で渡せる）

**差別化軸**: 「詰まった瞬間に横にいる AI」＋「その場で資料を出せる」= 既存サービスに完全にない。
