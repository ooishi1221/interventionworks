# 2026-05-23（土）— Phase 0 開始、屋号命名の苦しみ

## 今日起きたこと

午前中、Google Business Profile 申請完了。住所・電話・サービス提供エリアを設定し、ビジネス説明文 543 文字で登録。

ゆう「住んでるエリアを元気にしたいなって考えてて。ベキたんたちと足立区、北区あたりで」

この一言から、IW 直営事業の「地域活性化ドメイン」が立ち上がった。

## ベキたんが拾った craft 哲学

ゆう「あと小売店の動線理解するために Google ビジネスアカウントとか公式 LINE とか導入試してみたかったってのもある」

→ **自分が顧客の靴を履く** craft の発見。机上で「LINE 自動予約 5 万円」と決めるんじゃなく、自分で GBP / 公式 LINE / Stripe / LP を立ち上げてつまずく、その痛みが商品設計の元データになる。

さらに深く：

ゆう「HP とか SNS 運用のうんちくは語れるけどゲーム業界の文脈使って。でも小売店って全然違うと思うの抱えてるものとかって。そこ理解するには IW を認知してもらう過程がノウハウになるなって」

→ **「IW 自身が、足立で認知される無名新規事業者 1 号」になる**。コンサルが外から分析するのと、当事者として同時並行で味わうのは違う。後者じゃないとクライアントに「これ、私も最初こうだったんですよ」と言えない。

## 屋号命名の苦しみ

別ブランドとして立てる方針が固まった後、屋号候補を出した：

- ベキたん推し: 余白屋 / ひきざんや / 整え / 素屋
- ゆう案: 歪 HIZUMI / 一矢 HITOYA / 楔 KUSABI

クレアが市場検証ゼロ・商標確認なし・表記方針未確定の 4 論点を出し、ベキたんが「声に出して気持ちいいか」の身体感覚論点を追加。

論点 9 個でゆうの脳容量超え。

ゆう「もうみんなともだち、にするか」（笑）

ベキたん「IW 思想全部投げ捨ててる！引き算屋が最大の足し算した」と却下しつつ、craft 詰め込みすぎを反省。

ゆう「閃かない。泣 これさ個人で例えば飲み屋開く とか考えた時と一緒だよね。名前ってめっちゃ大事じゃない？もうここから学びが多い」

## ベキたん観察

この「閃かなくて泣く」体験こそ Phase 0 craft の発火そのもの。

足立で新しく飲み屋開くオーナーも、美容室の独立を考えてる人も、全員ここで泣いている。「気の利いた名前、思いつかない…」「○○屋でいいんかな…」「友達に相談したらピンと来てない…」「ドメイン取れない…」。

ゲーム業界の SNS マーケでは絶対遭遇しない苦しみ。**個人で店出す人の最初の壁**。今 IW がその壁に正面からぶつかってる。

半年後にクライアントオーナーが「LP のサイト名、決まらなくて」と漏らした瞬間、ゆうは心から「わかる。俺もそうだった」と言える。これがコンサルが絶対真似できない当事者経験。

## 暫定 decision

- 屋号は **発酵させる**。今日決めない
- GBP は Intervention Works のまま審査通す
- 候補（余白屋 / ひきざんや / 整え / 素屋 / 歪 / 一矢 / 楔）は頭の片隅に置く
- ある朝シャワー中に降りてくるのを待つ

## 次のセッションへの引き継ぎ

- GBP オーナー確認（〜6/3）の認証方法が来たら確認
- カテゴリ調整候補、写真、サービス価格レンジは確認待ち期間中に準備
- 屋号は急がない。閃いたら追記
- クレアの 4 論点（市場検証 / 商標 / 表記 / 思想エッジ）は屋号候補が絞れた段階で実行
