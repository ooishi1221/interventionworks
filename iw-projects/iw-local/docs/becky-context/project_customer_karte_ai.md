## core 価値命題

**「銀座ホステス品質」×「最短入力」× カスタム可能なテンプレ**

- 大手 CRM (Salesforce 等) = B2B 営業向け、個人店主 / 一営業マンには overengineering
- 美容室特化 SaaS (SALONBOARD 等) = 予約 + カルテ統合、ただし「銀座ホステス級」深さじゃない
- 個人事業主 / 営業マンの手書きノート = 検索性ゼロ、属人化、思い出せない

→ ニッチ market：**「個人 / 一営業マン向け、ホステス品質、AI 最短入力、業種別カスタム」**

## 入力 UX の核：「選択肢から消す」

裕司の core 観察：

> 「定型的なものは選択していくと項目がガンガン消えていく
> あとは個別にメモを書くかボイスレコーダーで文字起こす みたいなイメージ
> 接客の合間とか時間がある時に爆速でフレームを作っておくみたいな」

「フル入力」じゃなく「選択肢からチェックを潰す」craft tree。接客直後 30 秒で枠が埋まる。後で空き時間に個別追記。

- チェックボックス / タグ式の定型項目
- 自由メモ枠（個別エピソード用）
- ボイスレコーダー文字起こし → AI が定型項目に自動振り分け候補

### 実装した機能（確定仕様）

1. **外観入力 = 5 方向フリック × 5 部位**（最大 25 設問を片手で）
   - 画面のどこでフリックしても方向で遷移（人体の当たり判定は廃止。「タップした所が合わせられない」イライラを解消した最終形）
   - 部位マップ: 上=頭部 / 左=装飾ブランド / 右=特徴 / タップ=上半身 / 下=下半身
   - 各部位ズームも同じ 5 方向操作で統一。選択肢は全画面カード + 各カテゴリ「＋自由入力」で定型外も即追加
   - 合成距離(Math.hypot)で左右フリック判定。感度 FLICK_MIN=40px
2. **人体が「入力するほど金色に光る」**（litFill/litStroke/litWidth、充足度 ratio で濃さ・線の太さが変化）。ゆうの「入力した部分に色が塗られて人間が出来上がる」発案。飾りでなく**入力進捗のキャンバス**
