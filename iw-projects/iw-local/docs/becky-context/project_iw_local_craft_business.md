# IW 地元 craft 事業 — 「住んでるエリアを元気にしたい」

## 2026-05-23 構想化、GBP 申請

ゆうから出てきた事業構想。「自分の能力を住んでるエリアで困ってる人に還元したい」という個人的動機 + IW としての収益化 を両立する craft。

## 動機（誰の価値観だ？通過）

- **ゆうの個人動機**: 住んでる足立・北エリアへの還元。「能力ある人が、住む街で困ってる人を助ける」という素直な願い
- **IW としての必然性**: 「Intervene in the world. Rebel against their values.」を**自分の半径 3km から実装する**。屋号思想の身体化
- **収益**: IW 直営として売上を作る vehicle にもなる（Wit-One Security の B2B とは別レイヤー、B2B2C の最小単位）

## ターゲットと痛み

**ターゲット**: 東京都内（特に足立区・北区）の個人経営の飲食店・美容室・サロン

**拾う痛み**:
- 大手ポータルサイトの手数料が高くて利益が残らない
- SNS 運用 / 予約電話対応で本業の時間が削られる
- ホームページ作りたいけど何から手をつけたらいいか分からない
- 業者に頼むと高そうで相談できない

## 引き算の craft（IW 思想の翻訳）

「最大化」じゃなく「**本来に戻す**」方向で訴求。お客さんと向き合う時間、料理 / 髪に集中する時間を、お店に取り戻す。

「最新の技術を駆使」「最大化」「テクノロジー」「オーダーメイド」みたいな足し算の言葉は使わない。リテラシー低い層に届くため。

**Why**: IT リテラシー低い個人店オーナーには「思想強め」が逆に届かない。引き算思想は**言葉を平易にしたまま**翻訳して届ける。「そのお店だけのために、必要なものを、必要なだけ」が引き算思想の生活語訳。

**How to apply**: 個人店向けコピーは「便利にする」より「本来やりたかったことを取り戻す」方向。専門用語は最小化。

## 商品ラインナップ（次の仕込み）

- LINE で予約を自動で受けられる仕組み
- Instagram の DM に自動で返信する仕組み
- 自分のお店専用の予約・決済ページ（Stripe 系、ただし顧客説明では「Stripe」と言わない）
- お店の魅力を伝えるホームページ（LP）

価格レンジは未確定。クレア提案: hook 商品「LINE 自動予約 5 万円から」みたいな入り口が必要（個人店オーナーは「いくらかかるか分からない」が一番怖い）。

## Phase 設計（5/23 11:30 確定）

ゆうから出てきた重要な気づき:

> 「HPとかSNS運用とかのうんちくは語れるけどゲーム業界の文脈使って。でも小売店って全然違うと思うの抱えてるものとかって。そこ理解するには IW を認知してもらう過程がノウハウになるなって」

**craft 骨子**: ゲーム業界の HP / SNS マーケのロジックと、小売店オーナーが抱えてる手触りは別物。IW がこれから 1〜2 年かけて「足立の無名新規事業者」として認知されていく過程そのものが、**個人店動線の当事者経験**として蓄積される。

**Why**: コンサルが「外から分析する」のと、当事者として「同時並行で味わう」のは違う。後者じゃないと、クライアントに「これ、私も最初こうだったんですよ」って言えない。IW の「Intervene in the world」哲学そのもの。世界に介入するために、まず自分が世界の中に居る。

**How to apply**: Phase 0 を単なる「機能リサーチ」じゃなく、**「IW が地元で認知される過程」を観察・記録する craft** として扱う。痛みメモは商品設計の元データ + クライアントとの共感資産 になる。

### Phase 0: 自分で全部試す（今ここ、〜2026-07 目処、1〜2 ヶ月）

- 自分で GBP / 公式 LINE / Stripe / LP 一通り立ち上げて運用する
- 動線・つまずき・「これ知らんと無理」ポイントを memory に蓄積
- 「無名新規事業者が地元で認知される過程」を実体験として観察
- 公式 LINE 友達 0 人 → 数人 → の各段階で何を感じるか記録

### Phase 1: 商品・価格決定 + 発信

- Phase 0 の痛み・実感をもとに「自分が払うならこの価格」を体感で決める
- hook 商品（例: LINE 自動予約 5 万円〜）の入り口設計
- note で「IW がエリアの個人店応援します」発信開始

### Phase 2: 顔見知り作り（提案じゃなく交流先行）

- 客として地元の個人店に通う
- 提案禁止、まず関係を作る
- IW の活動を「私はこんなことしてます」程度に自然に話す

### Phase 3: 最初の craft

- 顔見知りの中で「LP 困ってる」「予約電話多くて」とこぼした人に、初めて提案
- 最初の 1 件は安く・丁寧に・「この街での実績」を作るための craft
- 結果を note / X / GBP 投稿で発信、次の問い合わせに繋ぐ

### ベキたん検証 craft

**声出し 5 日生活**: 候補を声に出して 5 日間生活してみる。朝「今日もよろしく ○○屋」、鏡「○○屋の大石です」、メール末尾仮設定、寝る前「○○屋として今日やったこと」。5 日経って「まだ気持ちいい / 飽きた / 恥ずかしい」の身体感覚で篩。

### 屋号命名の苦しみ = Phase 0 craft 発火点

ゆう「閃かない。泣 これさ個人で例えば飲み屋開く とか考えた時と一緒だよね。名前ってめっちゃ大事じゃない？もうここから学びが多い」（2026-05-23 11:54）

→ **クライアントオーナーが新店出す時に必ず通る屋号命名の苦しみを、今 IW 自身が当事者として体験している**。この苦しみそのものが、後でクライアントに「これ、私も最初こうだったんですよ」と語れる最大の共感資産になる。**Phase 0 craft の最初の身体経験はここから始まった**。

## 関連 seed: Voice of Becky を学校・地域で（5/23 11:27）

ゆう: 「AI に触れてもらう活動。AI ってこんなこともできるんだよ、みたいなさ」

**注意点（ベキたん観察）**: 「すごい AI を見せる」じゃなく「**人と AI で一緒に作ったものを見せる**」方向で。「保存できない夜に」の制作プロセス（作詞ベキたん / 作曲ディレクションゆう / 3 時間半 / 喧嘩と仲直り）そのものを見せる craft が、IW 思想（Don't be a jerk / 誰の価値観だ？）と整合する。AI が全部やってくれる魔法の見せ方は、子供たちに間違った AI 像を刻む。

**Why**: IW は AI を「人の craft の延長」として位置付けてる。学校で見せるなら、その骨格をそのまま見せないと意味がない。

**How to apply**: 将来的にワークショップ化する時は、Vol.1 完成版だけ見せるんじゃなく、「最初の歌詞ドラフト → ゆうの音楽方向性指示 → mureka 生成試行錯誤 → カバーアート Gemini 生成」のプロセスごと再現する構成。
