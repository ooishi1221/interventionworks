# Slight 仕様判断ログ

製造工程で発生した仕様判断と、その判断軸（「誰の価値観だ？」「引き算するもの」「触覚の感度」）を残す。後から営業エビデンスとして引ける形にする。

---

## 2026-05-28 — インジケーター判断保留 → 実機テストに依存

**判断:** インジケーター付ける / 削除する / 現状維持 の最終判断を**保留**。**2nd sample の実機温感テスト**を先行させ、結果で分岐する。

**Why:**
- 5/26 に「pinhole 化（no-mold 維持）」を依頼 → Stella 返信「pinhole = mold 必要、$1100-1300（17-20 万円）」
- mold コストは CF 投資額 30 万円に対して 60% 増、150 万円売上に対して 11-13%。CF 凍結（14 日 50% 未達）で焦げ付くリスク重い
- もう一度立ち戻ると、**インジケーターは「1st sample で電力 5W 弱く、ついてるか分からなかった」問題への band-aid だった**
- 2nd sample で電力 5W → 10W に倍増済 → 温感十分なら **インジケーター自体が不要**になる可能性
- Slight の引き算系譜（USB ケーブル / 物理スイッチ / 装飾）と同じ思想で、「機能の妥当性そのものを問い直す」が craft 正解

**How to apply:**
- 実機テスト判定基準: エンジン ON から 30 秒以内に明確な温感あれば「十分」
- 十分 → Stella にインジケーター削除 GO → ロゴ印字直行
- 不足 → 現状 no-mold インジケーターのまま受け入れ（mold 投資はしない）
- どちらでも「mold 払って pinhole 化」の選択肢は採らない（凍結リスクに対してコスト合わない）

**やり取りログ:** `stella-correspondence/2026-05-26_indicator-size.md`（5/28 返信ドラフト含む）

## 2026-05-26 — インジケーターライトの小型化依頼（→ 5/28 結果で再判断）

**判断:** インジケーターは存続。**サイズだけ大幅縮小**を Stella に依頼（pinhole-sized LED 目標）。位置（手首カフ・ソケット隣）は維持。

**Why:**
- インジケーター自体は**裕司発の機能要件**。サンプル 1 弾で「刺さってるか・通電してるか分からない」という実用課題があり、走行中に「あれ温まらない」が起きないために必要
- ただし**現サイズは Slight の世界観に対して主張しすぎ**。Slight が引き算するのは「機能を主張する記号」。インジケーターは「あるけどほぼ気付かない」が正解
- ロゴ印字前の今が、引き返せる最後のタイミング

**How to apply:**
- 「barely noticeable」「pinhole-sized LED」「no-mold approach 維持」の 3 点が依頼の効きどころ
- Stella からの返答で**現物比較写真**を必ず受け取る（「pinhole-sized」は解釈幅があるため）
- 小型化確認後にロゴ印字 GO

**やり取りログ:** `stella-correspondence/2026-05-26_indicator-size.md`
