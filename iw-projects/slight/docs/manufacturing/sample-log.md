## 2026-06-04〜08 — new version テスト結果: 4秒温感 / 30秒最高温度

**Stella からの進捗報告（写真 2 枚付き）:**
- `samples/2026-06-04_sample3_new_version_worn.jpg` — 着用 + 電力計（7-8W）
- `samples/2026-06-04_sample3_new_version_flat.jpg` — 平置き、インジケーター点灯確認

**テスト結果:**
- **4秒で温感 / 30秒で最高温度到達** — 5/28 判定基準（30秒以内に明確な温感）を完全クリア
- 出力: 7-8W / 温度: 一般的なグローブの高温レベル
- インジケーターは電源 ON 即点灯（現状は存在している）

**Stella の返信（2026-06-08）:**
- スイッチなし設計のため、インジケーターがないと「壊れてる？」と思うユーザーが出る
- 4秒の熱感遅延 → 加熱素子は即熱でも皮膚への伝達に遅れがある
- インジケーターは「システム起動確認」の役割で必要と判断
- 現在は fishing lamp の光を使用 → 通常より明るい / 夜間照明の差別化にもなると提案

**裕司の決断（2026-06-08）:** インジケーター採用で OK。ただし**位置は手首下側へ変更提案**（手の甲だとシルエットへの主張が強すぎる）
→ Stella に手首下配置の実現可否を確認する返信送信済（2026-06-08）。Stella 返答待ち。

## 2026-05-28 — インジケーター判断、実機テストに依存する craft へ転換

5/26 に「pinhole 化（no-mold 維持）」を Stella に依頼 → Stella 返信「pinhole = mold 必要、$1100-1300」。判断を一度立ち戻して再構築:

- 1st sample = 5W / インジケーターなし → 「ついてるか分からない」問題
- 2nd sample = 10W に倍増済 → 温感十分ならインジケーター不要
- つまり**インジケーターは電力弱さの band-aid**、根本（電力倍増）が効いてるなら band-aid 外せる
- 5/28 14:19、Stella に「実機テスト後数日内に最終判断」と返信送信済（`stella-correspondence/2026-05-26_indicator-size.md`）

**判定基準:** エンジン ON から **30 秒以内に明確な温感** → インジケーター削除 GO / 不足 → 現状 no-mold のまま受け入れ。mold 投資（17-20 万円）は CF 凍結リスクに対して合わないので採らない。
