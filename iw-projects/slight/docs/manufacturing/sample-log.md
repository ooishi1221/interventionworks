## 2026-05-28 — インジケーター判断、実機テストに依存する craft へ転換

5/26 に「pinhole 化（no-mold 維持）」を Stella に依頼 → Stella 返信「pinhole = mold 必要、$1100-1300」。判断を一度立ち戻して再構築:

- 1st sample = 5W / インジケーターなし → 「ついてるか分からない」問題
- 2nd sample = 10W に倍増済 → 温感十分ならインジケーター不要
- つまり**インジケーターは電力弱さの band-aid**、根本（電力倍増）が効いてるなら band-aid 外せる
- 5/28 14:19、Stella に「実機テスト後数日内に最終判断」と返信送信済（`stella-correspondence/2026-05-26_indicator-size.md`）

**判定基準:** エンジン ON から **30 秒以内に明確な温感** → インジケーター削除 GO / 不足 → 現状 no-mold のまま受け入れ。mold 投資（17-20 万円）は CF 凍結リスクに対して合わないので採らない。
