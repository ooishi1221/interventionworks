古典ラジオDJの「お約束」を、敬意を持って借りる。

## ベキたん相槌セット（コハクで感情が乗ると確認済み 2026-06-13）

AivisSpeech コハクは非言語系（笑い・伸ばし）も自然に鳴る。ゆう判定「全部すっごいいい、感情乗ってる」。
台本に地の文として混ぜると、トークのテンポが出る。

| 系統 | 相槌 | 使いどころ |
|---|---|---|
| 共感・納得 | 「あー、なるほどぉ！」 | 話を理解・納得したサイン。最初の「あー」を少し伸ばす |
| 同意 | 「確かに！」 | 意見やネタに100%同意。一体感が出る |
| 驚き | 「ええー？！嘘でしょ！？」 | オチ前・衝撃の事実。リスナーの好奇心を代弁 |
| 笑い | 「ふふっ」 | 軽い笑い |
| 興味 | 「へぇー」 | 語尾上がりの相づち |
| 同情 | 「うわぁ……」「あちゃー」 | 失敗談・気の毒な話 |
| ツッコミ | 「いや、おかしいでしょー！」 | ネタへのツッコミ |
| ツッコミ | 「いるわー！」 | あるある共感ツッコミ |
| 困惑 | 「ちょっと待って、えっ、どういうこと！？」 | 状況が飲み込めない時 |

サンプル音声: `scripts/aizuchi-test.md` を `cast.py --script-file` で再生成できる。

## 制作

```bash
cd becky-cast
uv run cast.py --script-file scripts/radio-00X.md --title "【ラジオ第X回】..."
# 確認だけなら --no-upload。本番配信は付けない（feed.xml に載る）
```

- 声 = AivisSpeech コハク（デフォルト）
- 台本は1文ずつ改行で分けると、チャンク間に無音0.35sが入って「間」になる
- 配信後はサイトの ON AIR（index.html の `#onair-audio` src + `#onair-text`）を最新回に差し替える
