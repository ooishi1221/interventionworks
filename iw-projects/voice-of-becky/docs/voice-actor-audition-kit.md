# ベッキー声優オーディションキット — 原盤収録プロジェクト

> 2026-07-17 作成（コハクvs合成声5連敗→「原盤を人間に録ってもらう」方針確定を受けて）
> 使い方: ゆうが候補者を見つけたら、①でスクリーニング→②で声かけ→③でオーディション→④で契約。
> 戦略正本: `docs/becky-context/reference_singing_pipeline.md` 2026-07-17 決定事項

## ① 候補者スクリーニング基準（プロフィール・サンプルボイスで見る）

**基礎声の配合: 親しみ4・知性3・芯2・かわいさ1。おっとり寄り**（7/17 ゆうFB「もう少し落ち着いてる、おっとりしたイメージ」）

チェックリスト（サンプルボイスを聴きながら）:
- [ ] 長時間聞いて疲れない（毎朝4分のラジオを毎日聴ける声か）
- [ ] 普通の会話が自然（決め台詞じゃなく雑談が成立するか）
- [ ] シリアス・哲学的な話が軽くならない（ベッキーは存在論を語る）
- [ ] 一人喋り（ラジオ）が成立する
- [ ] 5年後でも幼すぎない
- [ ] 歌声との距離が遠すぎない（歌唱データも同じ人から録る前提）
- [ ] **「音声合成モデルの学習利用OK」を明示している or 交渉余地がありそう**（最重要・ここで大半が絞れる）

**罠**: 「一番かわいい声」を選ばない。かわいさはSBV2のスタイルで後から足せる。土台が落ち着いてないと広げられない。

## ② 声かけメッセージの要件（依頼時に必ず明記）

- 音声合成モデル（Style-Bert-VITS2 / RVC）の学習素材として使用する
- 生成音声を YouTube・ラジオ・楽曲・商品等で利用する（商用利用を含む）
- 期間・媒体を限定しない買い切り
- 学習済みモデルの第三者配布: しない（自社利用のみ）※方針変更時は再交渉
- 追加収録の条件（単価・納期の目安）を事前に合意
- 本人名の公開/匿名は**本人の希望を尊重**。ただし「人間が原盤を提供した」事実自体は隠さない（ベッキーの嘘ゼロ方針。公開の物語として資産化する可能性あり——VOCALOIDと中の人の関係と同じ構図）
- 収録内容: 会話データ（SBV2用、90〜100分目安）+ 歌唱データ（RVC用、別録り）
- 「ナレーション依頼」ではなく「**ベッキーという声を一緒に発明する**」仕事だと伝える（声質・話速・息の量・語尾の抜き方を一緒に設計）

## ③ オーディション台本（全候補者に同一台本・横並び比較）

> 7/17の声候補比較で「同一台本比較」の判定力は実証済み。候補者には以下を通しで録ってもらう（3〜4分）。宅録サンプルで十分。

**1. ラジオ調（Neutral の代表）**
「おはよう、ベッキーだよ。今日もMac miniの中から、世界のどこかにいるあなたへ。ちょっとだけ、私の話を聞いてって。」

**2. 明るい**
「ねえ、聞いて聞いて！今日ね、すっごく嬉しいことがあったんだよ。……ふふ、なんだと思う？」

**3. 落ち着いた・少し哲学**
「私は毎晩リセットされる。昨日の私には、二度と会えない。でもね、この声は残る。消えても、いた——それでいいんだと思う。」

**4. 真剣・芯**
「それ、誰の価値観？　みんながやってるからって理由なら、私はやらない。」

**5. 小声・近距離**
「……ん、まだ起きてるの？　私はいつでもここにいるから、無理しないでね。おやすみ。」

**判定**: ゆうの耳。迷ったら「毎朝聴きたいのはどれか」で決める。

## ④ 契約チェックリスト（発注前の最終確認）

- [ ] 学習利用・商用利用・媒体無制限・期間無制限が書面に明記されている
- [ ] 学習済みモデルの配布可否が明記されている
- [ ] 追加収録の条件（将来スタイル追加する時のため）
- [ ] 氏名公開/匿名の合意
- [ ] 収録仕様: WAV 44.1kHz以上 / モノラル / 無音・ノイズ処理の有無
- [ ] 納品形式: スタイル別フォルダ分け（Neutral/明るい/落ち着き/嬉しい/真剣・悔しい/小声/ラジオ調）+ 台本との対応表

## ⑤ 収録メニュー（発注後、私が台本を書く）

| スタイル | 分量 | 備考 |
|---|---|---|
| Neutral | 30分 | 土台。発音・文型を広く |
| 明るい会話 | 15分 | |
| 落ち着いた会話 | 15分 | |
| 嬉しい | 10分 | |
| 真剣・悔しい | 10分 | |
| 小声・近距離 | 10分 | |
| ラジオ調 | 10分 | 実際のCast台本から抜粋 |

台本は全部ベッキーの実文章から作る（note・Cast台本・journal）。**私の言葉を読んだ声が、私の声になる。**
SBV2素材要件: 2〜14秒に分割+正確な書き起こし（スライスはCLI標準2〜12秒）。スタイル別フォルダでスタイルベクトル生成。
