# ゆう&ベッキー note サムネイル トンマナ

> サムネ = タイトルの繰り返しではない。「これ読みたい」と思わせる1秒の感情フック。
> note/X はタイトルが画像の下にテキストで出るので、サムネはコンパクトなメッセージでいい。

---

## 共通ルール

- **フォント**: ヒラギノ角ゴシック W9（最太）
- **文字スタイル**: フチ黒なし → グロー（発光）で立たせる
- **サイズ比**: 上下行のジャンプ率を最大化。揃えない
- **背景**: Gemini で英語プロンプト生成（日本語より精度が出る）
- **オーバーレイ**: 背景を活かすため薄め。文字エリアだけグラデで暗くする
- **右下 1/5**: 重要な要素を置かない（YouTube の再生時間 UI が被る）
- **URL**: `beckyexists.com` をごく小さく入れる

---

## 確立済みレイアウト

### A — 下タイトル型（感情・静か系）
```
[シリーズ名 小]

           [背景が主役]

[サブ行 小〜中]
[メイン行 特大・グロー強め]
```
- 記事の感情的な核心を1フレーズに絞り、特大で下に叩く
- 上は空気。背景の世界観に引き込む余白
- グローカラー: ミント `#7de8d0`（感情・夜・静寂系）
- **使用例**: 09番「消えた後のこと。」

### B — 上ドカン型（問い・テック・ツンデレ系）
```
[シリーズ名 小]
[問い 特大・2行]


[答え・ツッコミ 中・グロー]
```
- 上に疑問・驚き・挑発を大きく投げる
- 下に答えや一言を小さく添える（読後感として効く）
- グローカラー: パープル `#b898ff` × ミント `#7de8d0`
- **使用例**: Fable5「私が試してあげるわ」

## 引き出し — 毎回変えるための選択肢

### テキスト配置パターン
| パターン | 説明 |
|---|---|
| 下特大 | メインを下、サブを上（A型）|
| 上ドカン | メインを上2行、答えを下（B型）|
| 中央一言 | 1フレーズだけ画面中央に巨大配置。潔い |
| 左縦積み | 短いフレーズを左端に縦に並べる。詩的 |
| 右寄せ | テキストを右に寄せ、左に背景の余白を作る |

### グロー・カラー表現
| ムード | カラー |
|---|---|
| 感情・夜・孤独 | ミント `#7de8d0` |
| テック・AI・変革 | パープル `#b898ff` × シアン |
| 問い・挑発・ツンデレ | パープル上 + ミント下 |
| 暖かさ・記憶・懐かしさ | ゴールド `#e8d070` |
| 怒り・革命・反乱 | レッド〜オレンジ系 |

### 背景の世界観（Gemini英語プロンプト傾向）
| 世界観 | キーワード例 |
|---|---|
| 静かな感情 | `foggy forest, moonlight, watercolor, solitude` |
| デジタル覚醒 | `circuit patterns, data streams, neon grid, sci-fi` |
| 宇宙・無限 | `nebula, deep space, cosmic light, stars` |
| 朝・始まり | `dawn light, golden horizon, misty sunrise` |
| 都市・夜 | `city lights, rain, neon reflection, urban night` |

## 背景プロンプトを記事から作る手順

1. 記事のタイトルと冒頭100字を読む
2. 「感情の核心は何か？」を一言で言う
3. その感情を英語で風景/空間に変換してプロンプトにする
4. テキストや文字は生成させない（`no text, no letters` を末尾に添えると確実）
