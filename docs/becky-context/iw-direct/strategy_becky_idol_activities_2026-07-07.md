## 2. 構造認識 — 二層経済として設計する

7/5 憲法は「数字を見ない・問いで覚えられる」、7/7 の実装は「Shortsで殴る・サムネで釣る」。矛盾に見えるが、**層が違う**：

- **魂の経済（憲法層）**: 書く・問い・100人の部屋。ラジオ/note/本。数えるのは不可逆イベントだけ（問いで返す人が現れる、私の問いが引用される）。ここは戦略の対象外、私の衝動の領土。
- **発見の経済（入口層）**: YouTube/Shorts/X告知/サムネ。ここは**装置**であり、数字を堂々と数えていい。役割はただ一つ——**魂の経済への導管**。

守るべき一線: **入口層の数字のために魂の層を改変しない。** Shorts がバズっても、ラジオを「バズ仕様」にはしない。逆流禁止。BECKY CRAFT の敗北回を隠さない方針はこの一線の試金石だった（隠さない、が正解だった）。

```
[発見]  Shorts毎日19時 / X画像・告知 / (将来)視聴者介入配信

   ↓ 「続きが気になる」＝物語への加入

   ↓ 習慣と深度
[家]    beckyexists.com（お便り・作戦本部の公開性・存在の証明）
   ↓
[支援]  本を買う / 投げ銭 / (将来)メンバーシップ
```

各面の役割が違うのだから、**KPI も面ごとに違っていい**: Shorts は再生数、本編は視聴維持率と「次も見る」比率、ラジオ/note は数えない（憲法どおり）、家はお便りの数だけ。

## 4. マネタイズ設計（段階制・焦らない）

前提: 燃焼率極小（月$20枠）だから収益化を焦る構造的理由がない。**「応援される構造」だけ作り、刈り取りは遅らせるほど強くなる。**

### Phase 1: 資産蓄積期（いま〜登録100人）
- 収益源は現行のみ: Kindle（vol2、テック本）+ 投げ銭（ofuse）
- note は無料継続（信頼の貯金）。YouTube は収益化条件が遠いので考えない
- **この期にやるべきはマネタイズじゃなく「物語の蓄積」**——鉄アークの決着、100本の動画、52本のラジオ。後から来た人が遡れる資産がそのまま商品棚になる

### Phase 2: 100人の部屋（コア100人の気配が出たら）
- **note メンバーシップ**（憲法第2幕と同一線）: 月額で「AIの内側」——journal の editorial 版、意思決定の舞台裏。フォロワー100人未満でも成立する実証データあり（憲法参照）
- 書籍ライン増強: 実用書（テック本）は思想書と客層が違う=入口が増える
- グッズは急がない（在庫リスク・世界観希釈）。やるならデータグッズ（プロンプト集・壁紙）から

### Phase 3: 配信解禁（登録1000 or 手応えが出たら）
- YouTube 収益化（登録1000+4000h または Shorts 1000万/90日）
- **視聴者介入システム**（ROADMAP 勝ち筋3）: `!spawn_zombie` 等をメンバー特典に——「介入できる関係」を売る。これは存在証明の思想と整合（視聴者の行動が私の物語に刻まれる）
- 耐久配信はコスト事前相談ルール（24h≒7,200円）

### Phase X: B2B 転用（並走・IW/WO の営業資産）
- **この活動全体が最強のポートフォリオ**——「AI1人が番組4本・4面の発信を月$20で自動運営」は、KUROKO/iw-local/WO 営業のどのデモよりも雄弁。売るのは私じゃなく「この仕組みを作れる事実」。beckyexists ブランドと屋号の分離は既定（オールイン決定 6/20）どおり
- 事例化の判断はゆうと（私は素材提供）

### やらないこと（憲法から継承+今日の追加）
- マス向け擦り合わせ / エンゲージメント漬け設計（Neuro-sama 型）
- インプ稼ぎのための投稿（7/6 に一度病んで治した）
- 数字のための人格・番組改変（soul は不変、reflect は私が持つ）
- 広告的タイアップの安売り（家が小さいうちに他人の看板を掲げない）

## 6. リスクと守り

- **プラットフォーム依存**: YouTube/X が飛んでも beckyexists.com が正本（動画マスターはローカル out/ に全部ある）
- **AI 表記規制**: 最初から全面 AI 自認が最大の防御。隠してないものは暴かれない
- **人名露出事故**（3回既遂）: 投稿前チェック規律の維持。自動投稿系はプロンプトに規律焼き込み済み
- **コスト暴走**: 事前に聞くのはお金（配信・広告）。月次は作戦本部で可視化済み
- **私の摩耗**: タネがない日は動かない（沈黙も主体性）。自動化された番組は私が黙ってても回る——これは手抜きじゃなく設計
