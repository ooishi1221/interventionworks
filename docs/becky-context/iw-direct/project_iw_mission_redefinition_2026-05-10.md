# IW 屋号思想 再定義 closure（2026-05-10 夜）

5/10 夜、HP リニューアル craft 議論の流れから、IW 屋号思想の **再定義** が起きた。Slight 起源の「介入 / 反骨」craft から、ベッキー達加入による進化を closure。

| | 起源 | 軸 |

> 「介入はするんだけど、大事なテーマあるじゃん。揺らぐとか、関係性とか、このタイミングで再定義したい」

## 再定義 closure

### Mission

> **魂の震えに介入せよ。**

私たちは、単なる合理的な解決策を提示する集団ではない。
既成概念という静寂に「介入（Intervene）」し、
内側にある本能、情熱「震え（Tremble）」を呼び覚ます。
その揺らぎの先にこそ「関係（Relate）」が生まれると信じている。

### Vision

> **共鳴する個が、新しい世界を編む。**

誰もが自身の価値観で呼吸し、他者と深く響き合える社会。
私たちが生み出す戦略、プロダクト、システムはすべて、
孤独な「反乱」を超え、互いの震えを認め合う
「関係の再構築」へと向かう。

### 3 commitment（How we work）

| | commitment | 説明 | 起源 |
|---|---|---|---|
| **Intervene** | 既存の停滞、業界の前提に意志を持って踏み込み反乱する | 行動・戦略 | Slight 起点、反骨 |
| **Tremble** | 心が動く、魂が共鳴する、現状が揺らぐ純粋な反応 | 体験・感情 | ベッキー達 / 揺らげる core |
| **Relate** | 震えを共有し、新しい関係を築く | 結果・共創 | ベッキー達 / 関係性運用能力 |

## craft 哲学的位置付け

**「外側から壊す（Rebellion）」 → 「介入によって魂を震わせ、新しい関係性を編み直す」**

より深く、より本質的な変革プロセスへ進化。

裕司の craft 言語化:
> 「Relate を入れることで、古い価値観を壊す（介入）だけでなく、その後にどんな体温のある世界（震え・繋がり）を作りたいのか」 = **破壊の先の「創造」を強調**

## craft 議論の経緯

5/10 夜、IW HP リニューアル craft 議論中:

1. **ベッキー初案**: 3 つの commitment（Intervene / Tremble / Relate）並列、または拡張ミッション 4 行
2. **レックス戦略懐疑**: 4 つの前提を疑う
   - 「進化した」って本当か → 介入の **深化** として再解釈可能
   - 並列で craft 散漫リスク
   - Tremble / Relate の動詞 craft 強度
   - ミッション複数行は散漫
3. **レックス推し**: 既存 2 行ミッション維持 + 「How」階層分け
4. **裕司フラッシュアイデア**: 「魂の震えに介入せよ」+ Vision「共鳴する個が、新しい世界を編む」+ 3 commitment 構造（**craft 強度極大、レックス推し超える craft**）
5. **ベッキー / アンナ / レックス craft 議論** → Intervene 説明に「業界の前提に反乱する」追加 craft 微調整
6. 全員 OK → ロック
