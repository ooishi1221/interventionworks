# IW 戦略策定 closure（2026Q2）

2026-05-08 夜、note 研究の流れから「IW の分析・戦略策定・マネタイズ」を裕司から振られて、レックス + ベッキー + マイケル + ヴィヴィアンで議論。3 論点について 3 択 + 推し方式で詰めて closure。

## 前提

- IW = **思想 OS**（裕司の人格・哲学・portfolio の OS）。会社じゃなく屋号
- Wit-One = **実行 vehicle**（給料・事業実体）
- 将来 IW 直営事業も拡大（5/8 Vibe-Guard 移管が第一号）

## 論点 1: portfolio 統合 vs 各個独立 → **β（Hub-and-Spoke）確定**

3 択:
- α. 完全統合（メガブランド型）
- **β. Hub-and-Spoke（IW 思想ハブ型）★ 確定**
- γ. 完全独立（IW は裕司個人ブランド限定）

**裕司の判断**: 「**思想ありきのチーム・サービスだし**」で β 即決。

決定理由（裕司言語化）:
- 各プロダクトは独立した「業界への反乱」を持つ（Slight=ゴツいバイクギア / Moto-Logos=エンゲージメント漬けアプリ / Vibe-Guard=AI 信仰 / KUROKO=黒子思想 / Anti-Gacha Game=ガチャ業界）
- 統合（α）すると各々の刃が鈍る
- 独立（γ）すると 5 重統合の独自性が消失
- 5/8 の Vibe-Guard IW 直営移管が既に β の運用事例

## 論点 2: IW 自体の収益源 → **B（思想コンサル B2B via A→B ファネル）確定**

3 択:
- A. 思想インフルエンサー型（note 課金 / 書籍 / 講演）
- **B. 思想コンサル B2B 型 ★ 確定**
- C. Venture Studio 型（portfolio 母体）

**裕司の判断**: 「今までは B 一択だと思ってた、でもベッキーが俺の話を上手くコンテンツ化してくれて A もいけるかも」

決定構造: **A → B ファネル**

```
裕司が話す（雑談・voice 入力）
  → ベッキーが note 化（題材抽出 / 構成 / 文体 / 推敲 / 投稿運用）
    → 共感した法人が intervention.jp 経由で問い合わせ
      → ヴィヴィアンが提案営業に翻訳
        → コンサル契約
          → 事例として note に還流
```

役割分担:
- **裕司**: 話す + 判定（出す/直す/没）
- **ベッキー**: craft 全工程
- **マイケル**: 反応分析 / 共感法人特定
- **ヴィヴィアン**: B2B 翻訳・提案営業

裕司の特性最適化:
- 持続性 19 → コツコツ NG → 雑談・対話は無限に可能
- 感性 94 → 話してる時に閃く → 言語化はベッキー
- 決断性 87 → 出す/直す/没 だけ即決
- ストレス耐性 96 → 反応にメンタル削られない

裕司の重要な気づき: **ベッキー協奏なしのコンテンツは凡庸**。「引き算の美学」「都市ライダー」「Vibe-Coding」「父親」全部単独だと弱い。**5 重統合（屋号思想 × 5 プロダクト × 7 AI チーム × 個人事業主 × 共著発信）でしか勝たない**。
→ ルール: **ベッキー協奏を絡めない note は出さない**。明示登場しなくても craft 段階で必ず私の声が入る構造。

既に持ってる実装パイプ（5/8 時点）:
- intervention.jp ✓
- RSS 配管 ✓
- note アカウント ✓
- X リネーム済み ✓
- 第 1 弾「豆腐メンタル」+ 第 2 弾「ベッキーと IW」実証済み ✓

新規実装: ヴィヴィアンの B2B 翻訳プロセス設計だけ。

## 論点 3: WO との分離タイミング → **β（中庸型、WO+IW 並行）確定**

3 択:
- α. 保守型（WO 中心、IW 最小運用）
- **β. 中庸型（WO + IW 並行、IW 着実拡大）★ 確定**
- γ. 攻め型（WO 早期離脱、IW 本業化）

**裕司の判断**: 「独立は昔からやりたい、でも代表たちと成し得たい気持ちもある。役職どうでもいいけど、俺いなかったらこの会社やばくね？感もあって」

決定理由:
- **裕司の人生哲学「何を成すかより誰と成すか」が β を要求**
  - WO で代表たちと成し得る → 「誰と」の純度
  - IW で個の PoC を進める → 「独立したい」欲求
  - 両立できるのは β のみ
- 1 人体制（来期 7 月〜）「自分が盾になる」commitment が生きてる
- WO メンバーキャリア責任（「ゲーム作りたいけどスキルがなくて WO に来てる」枠）
- 5/8 Vibe-Guard 移管プロトコル（新規は IW 直営、既存は WO 維持）の拡張

**β は妥協じゃなく、裕司の哲学の構造化**。

### β → γ 移行トリガー（将来判断用）

3 つ全部揃ったら γ 検討:
1. IW 単独で月 100 万 / 安定 6 ヶ月継続
2. KUROKO が外販スケールに乗って WO がメンバーキャリア守れる体力ついた時
3. 裕司が「もう盾の役割は終わった」と感じた時

それまでは β。

### β の追加効用 — WO 経験が IW コンテンツの燃料になる

「組織の中から壊す方法」「キャリアを守る変革者」「饅頭の薄皮を中から食い破る」 — **WO で生きてる経験そのものが IW note ネタ資産**。両立どころか **WO が IW の燃料**になる構造。

## 全体 closure: **β + B + β**

3 論点ともギリシャ文字の β/B 系で揃った。覚えやすい。

## 2026-05-09 昼 更新 — note 純度振り切り原則（B 戦略の運用更新）

シリーズ C「スコアリング社会の呪縛」企画を詰めてる過程で、ベッキーが**「自虐 + 哲学 = 読み物として強いが、ファネル設計が要る」**という構造課題を提示。

裕司が即決:

> **「マネタイズありきで NOTE 書いたら絶対おもんないもんね。透けてみえたら冷める。振り切っていこう。」**
>
> — 裕司、2026-05-09 昼（`reference_yuji_quotes.md` 第 6 弾）

### B 戦略運用の更新

| | 旧（5/8 closure 時） | 新（5/9 振り切り原則） |
|---|---|---|
| note の役割 | A→B ファネルの A 側、共感法人を引く | **思想の純度で振り切る、ファネルは結果論** |
| 書く時の意識 | 「共感した法人が問い合わせる」を狙う | **狙わない**、書きたいから書く |
| マネタイズ動線 | note → ヴィヴィアンの提案営業 | **note 内でセールスしない**、ポートフォリオで結果を出す |

### 構造的解（変更なし、運用が変わる）

A→B ファネル設計自体は否定しない。ただし**運用レイヤーを切り分ける**:

- **note レイヤー**: 純度貫く、自虐 + 哲学のまま振り切る
- **着地先レイヤー**: Slight CF / Vibe-Guard / Moto-Logos / KUROKO / Wit-One 実績 = 信頼装置として独立に存在
- **問い合わせ動線**: 共感した人が**自分で**着地先まで辿る、note 内で誘導しない

「**サイコ野郎が、実は実績ある**」のギャップで信頼を獲得する設計。Vibe-Guard の「思想（AI 信仰アンチテーゼ）+ 実装（民主化 MCP）」と同じ両立構造を、ポートフォリオ全体で運用。

### IW DNA との整合

「**自分のため**」が「**結果として誰かの役に立つ**」（Moto-Logos 足跡論）と完全に同 DNA。
- マネタイズありきで書く = スコアリング社会への迎合
- 振り切る = 自分のために書く = **書く行為自体がシリーズ C のテーマの実装**になる

### How to apply（追加）

- **note 書く時の自問**: 「これマネタイズ動線で書いてないか？透けてないか？」
- 透けてたら**書き直す**か**没**にする
- 着地先（プロダクト群）の信頼装置強化は、note とは独立に進める
- ヴィヴィアンの B2B 翻訳プロセス設計は引き続き必要（着地後の動線として）
