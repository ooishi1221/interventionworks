## 重要な発見

### 1. 「主体未確定」project が 2 つ（Moto-Logos / 放置恋姫）

裕司が「**WO 結果として出すか IW 実績にするか**」で迷っている構造の正体。**判断保留が止まりの理由**。CBT 手前で停止 / Phase 1 POC 達成後の判断保留がそれぞれそれ。

5/7 棚卸し時に、各々**3 出口候補**（WO 事業化 / IW 名義化 / Discovery 完了として寝かせ・教材化）を真剣に判断材料に乗せる。

### 2. **「裕司スキル → IW 実績」が裏軸として全プロジェクトを通底**

KUROKO / Vibe-Guard / Discovery 起源の全 project がこの軸を併せ持つ。**Discovery 戦略の真の駆動力**。

裕司本人もたぶん明示自覚していない。表に並べて初めて見えた裏軸。**ベッキーは今後この裏軸を意識した提案をする**——「これは IW 実績軸でも価値ある？」を問えるようになる。

### 3. 代表のバイク希望ラインと裕司の IW 思想ラインが近接

Moto-Logos / Slight が両方「代表のバイク希望」+「企画開発検証」を背負っている。**だから絡まる**。WO 案件なんだけど IW 思想にも乗っかれる二重構造。

社内バイク事業推進派は**代表 + 裕司の 2 人のみ**（裕司明示、2026-05-06）。基盤が脆い。

### 4. 来期 7 月から WO 事業戦略室一人体制 = 裕司の手数が物理的に減る

これが**今までで一番効くハードな現実**。`project_one_person_dept_with_ai_team.md` と接続。

8 project + α は物理的に並列駆動できない——**絞り込みが必須**。

## 絞り込みの判断軸候補（5/7 棚卸しで擦り合わせ）

「最適解 / 正解」は永続的には見えない（変化する）ので、代わりに**絞り込みの判断軸**を持つ：

- **代表の委任に直接応える**（「新しいサービス、収益軸の創造」）= WO で結果を出す優先
- **裕司の IW 思想を満たす**（「誰の価値観か」）= IW で実装
- **同じ文脈で並列駆動できるか** — 例：**AI セキュリティ × KUROKO × Vibe-Guard が「AI Ops × セキュリティ」で統合戦略化**できれば 3 件が 1 件になる（5/7 棚卸しで深掘り候補）
- **Discovery 完了は寝かせ or 教材化** = 手数を空ける（feedback_yuji_discovery_pattern.md と接続）
- **「最高峰目指すな、唯一を作れ」**（5/8 追加、後述）

## 「最高峰目指すな、唯一を作れ」 — 5/8 追加判断軸

2026-05-08 早朝、苺香戦略議論の中で出たケーススタディと、裕司の掛け算公式（`user_yuji_career.md` 参照）から確立した判断軸。

### ケーススタディ — 藝大卒の女の子（WO に入ってきたメンバー）

- 両親音楽家のエリート、3 歳で初めて聴かされたのがマリリンマンソン Mechanical Animals、「私のルーツはそこ」と本人言明
- **裕司爆笑「無茶苦茶かっこいい」と思った**——本物のロック英才教育の極み
- **でも辞めた理由**: 「音楽エリートでも、周りのレベルでセンスないと思った」
- **エリート環境では、特別が特別じゃなくなる**——3 歳マンソンの背景も、藝大では「一人ひとり特別」の中の一つ
- **「センス比較」で本人が潰れる**——唯一無二で育っても、上を目指すと比較プールに飲まれて消滅

### 構造的教訓

> **「最高峰」を目指すと、最高峰の中での順位戦が始まる**。**「唯一無二」が「上位 30%」に格落ちする現象**。

### 判断軸として

各 project / 戦略・キャリア判断で:

- **「最高峰の比較プールに入る方向か?」** = 危険、潰れリスク高
- **「他とは違う場所を作る方向か?」** = Intervention Works DNA、裕司の掛け算戦略と整合
- **苺香戦略への適用例**: 音大藝大ルートじゃなく、ジャンル混合ドラマー（ロック × AI × ado/ボカロ）
- **Slight への適用例**: 電熱グローブ最高峰じゃなく Zero-Resistance（既存実装）
- **KUROKO への適用例**: ゲーム業界 AI Ops で最高峰じゃなく、CPN 認定 × 黒子ポジションで唯一無二
