## 2 軸の合体 craft

### 軸 1: Vibe-Cutter（メタ認知代行 + 発掘 craft）

**aho の本質 = 忘れてる、じゃなく「まとめる / 置き換える / 交換する」概念がない**（裕司 20:29 core 洞察）。

```
入力: ユーザーの subscribe（メール scan で受動取得が core）
↓
AI が言う:
  「Notion 入れてるなら Evernote、機能 95% 重複。置換候補」
  「Slack と LINE WORKS、まとめれる craft 提案」
  「Adobe CC 年 72,000 円 → Affinity 一括 7,500 円で 80% 代替」
↓
出力: 統合 / 置換 / 交換 craft 候補リスト
```

### 軸 2: Local-Hero（海外神 OSS の日本翻訳・伴走）

**「海外で valid な OSS / 神 tool が日本でマイナーリーグに留まってる」craft 隙間** = IW DNA「Whose values?」「ジャイアントキリング」と core 同型。

代表的な未到達神 OSS:
- Bitwarden（パスワード管理、無料 / OSS / self-host 可）
- Tailscale（VPN 革命、100 デバイス無料）
- Logseq（Notion 代替、OSS）
- Excalidraw（OSS ホワイトボード）
- Caddy（自動 HTTPS Web サーバー）
- EspoCRM（顧客管理、Salesforce 代替 OSS）
- Akaunting（会計、freee 代替 OSS）
- Cal.com（予約、Calendly 代替 OSS）
- InvenTree（在庫管理 OSS）
- Mattermost（Slack 代替 self-host）

## 発掘 craft（aho 受動取得 UX）

| craft | 取れる範囲 | aho 優しさ |
|---|---|---|
| **Gmail / Outlook メール scan**（推し core） | 過去 全部 subscribe 100% | 🟢 OAuth 1 click |
| クレカ / 銀行 CSV import（補助）| 過去 全部 | 🟡 CSV download 手間 |
| ブラウザ拡張で決済画面 capture（受動）| 未来分 | 🟢 受動 |
| マネーフォワード ME 連携 | 既存ユーザー強 | 🟡 API 要 |

**Bitwarden roll model**: ログイン画面で勝手に capture → 「保存しますか？」を押すだけ、の UX を subscribe craft に転用。

## 出口 craft（2026-05-25 段階の仮説）

| 出口 | 評価 | 観 |
|---|---|---|
| **🥇 iw-local の craft 武器**（個人店向け IT 伴走 spot + 月額）| 🟢 既存ドメイン直結、CF / SaaS 立ち上げ craft 不要 | **第一候補** |
| 個人向け SaaS（B2C 月 ¥500 freemium）| 🔴 distribution craft 重い、aho の財布小さい | 第二候補 |
| 中小企業向け SaaS（B2B SaaS）| 🟡 営業 craft 重い、Wit-One 余力ない | 第三候補 |
| Media + 厳選アフィリ + 月額コミュニティ | 🟡 収益化遅い、note 連載 craft と相乗 | 補助 craft |
| OSS 法人導入 spot コンサル（B2B）| 🟡 スケールしない、収益性高 | spot 武器 |

→ **「iw-local の事業 craft 武器」として組み込む craft が第一推し**。Phase 0 → Phase 1 craft 道筋がここで見える。

```
- 乗換伴走 spot 案件: 個人店 1 件 ¥30-50 万円（移行 + 設定 + 1 ヶ月サポート）
```

## クレア軸 risk 5 つ

1. **メール scan の盲点**: 死んでる service / 退会通知 OFF / 紙明細のみ → クレカ CSV 二段構え必要
2. **移行コスト = aho の壁**: passwords import すら重い → 「移行代行 craft」自体を商材化で裏返す
3. **OSS update craft 永続コスト**: 「これおすすめ」が 1 年後陳腐化、maintain 体制要
4. **OAuth で取れない情報多い**（日本クレカ API 閉鎖的）
5. **distribution craft**: target「SaaS 漬けの個人」発見 craft 重い → だから iw-local 出口が valid
