# Anti-Gacha Game（仮称）

ゲーム業界のガチャマネタイズへの構造的アンチテーゼ作品。**業界の本編を削除して、消費者が実際楽しんでる「リセマラ・準備」だけを残す**。Slight（引き算の美学）と同じ DNA、KUROKO portfolio 候補。

## 発案の文脈

2026-05-02 GW Day 1 closure 直前、裕司から「興味本位」で相談 → 議論で深まり「やろうかな」モードに転換。「組めそうなら仕様検討する」段階。

## Core Insight（裕司の業界 insider 観察）

### 業界の resource misallocation

- **業界の前提**: 「ガチャ = パチンコ」、演出の煽り = 娯楽
- **消費者の実態**: キャラ取得が目的、演出は **noise** として処理（5 秒スキップ）
- **裕司の証言**: 「会社でゲームやる子、リセマラして準備してる時が一番楽しい、その先でやめちゃう」
- → 業界は誤った仮説（パチンコ理論）で演出に億単位投資、消費者には響いてない

### リセマラの本質

「リセマラの楽しさ = **お金をかけずに、期待値高まる演出を、飽きない範囲で享受する**」

| 条件 | 重要性 |
|---|---|
| 無料（コスパ） | 演出の価値の前提 |
| 期待値高まる演出（pre-spike） | 楽しさの核 |
| 飽きない範囲（多様性 / スキップ自由） | 持続性の条件 |

### 期待 > 達成 の構造（神経科学・期待経済学）

| 段階 | dopamine |
|---|---|
| ガチャ引く前（anticipation） | **pre-spike**、最大の期待 |
| 引く瞬間（variable ratio） | spike（Skinner box）|
| 結果出た直後 | spike or fall |
| 結果定着 | 期待値に correction、減衰 |

→ リセマラ = pre-spike を無限ループする装置。

## Game Design

### コアメカニクス

**ステージ制リセマラ + メンテ強制移行**:

```
ステージ A（ドッカン風） → メンテまで 5 分、リセマラ加速 → メンテ強制 → 詫び石配布
ステージ B（ウマ娘風） → メンテまで 7 分 → 強制 → 詫び石
ステージ C（FGO 風） → ...
```

**スコア要素**:
- 獲得キャラ数
- 詫び石使用効率
- メンテ強制終了絶望体験回数

### ステージ案（業界主要タイトル「風」）

- A: ドッカンバトル風（アクション RPG、超派手 visual）
- B: ウマ娘風（育成、可愛さ爆発 SSR 演出）
- C: モンスト風（アクション + 友情コンボ）
- D: パズドラ風（パズル + ガチャ）
- E: FGO 風（ストーリー + 礼装）
- F: 原神風（オープンワールド + 元素）
- G: ブルーアーカイブ風（学園 + 戦術）
- H: お詫び石ガチャステージ
- I: コラボガチャステージ（ラーメン屋、家電量販店、世界観無視）

### 業界批判の二重構造

| 体験 | 業界の symbolize |
|---|---|
| メンテで強制中断 | 運営の権力、ユーザーの計画破壊 |
| 詫び石で慰める | 歪んだ信頼関係、補償が次のガチャへの再投資 |
| 焦って引く | 時間制限ガチャの業界お約束 |
| 「あと1回で天井」絶望 | 業界の運否天賦の象徴 |

### マネタイズ（業界批判の自己整合性）

- ❌ 課金なし（業界批判の core integrity）
- ⭕ 完全無料 or 買い切り or 広告
- 「魂を運営に捧げる利用規約」スタート画面隅に小さく挿入（メタ要素）

### 引き算の核心（Slight DNA）

**業界の本編を削除して、消費者が実際楽しんでる部分だけ残す**:
- ❌ 本編 RPG / バトル / ステージ
- ❌ ガチャ課金 / マネタイズ
- ❌ 強制スタミナ / レベル上限
- ⭕ ガチャ演出（多様性で飽きさせない）
- ⭕ リセマラの自由
- ⭕ メンテ強制終了の絶望
- ⭕ 詫び石の rituals

## 法的境界

- ❌ 直接タイトル名 / キャラ使用は NG（商標 / 著作権）
- ⭕ 「風」で aesthetic だけ inspired、独自キャラ + 演出ロジック → parody / fair use の境界内
- ⚠️ 弁護士相談案件（release 前）

## Gemini 比較分析（5/2 closure で実施）

裕司が同じ質問を Gemini にも投げた。Gemini の 4 案（サ終サバイバル / 虚無 RPG / ガチャシミュ / SNS タワーディフェンス）:

- ⭕ 業界 inside 用語の網羅性高い（お詫び石 / 凸 / 物欲センサー）
- ❌ ネタの羅列、構造的アンチテーゼじゃない
- ❌ 「業界の本音を foreground 化する」core insight 薄い
- ❌ 案 4 はゲームじゃなくコミュニティ風刺、お題逸脱

→ **我々（裕司 + ベッキー）の方が構造的に深い、Gemini は表層の網羅性で勝負**。
→ ただし Gemini からも cherry-pick できる素材あり（お詫び石ガチャ / コラボガチャ / 利用規約メタ要素）。
