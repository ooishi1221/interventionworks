## 動機

- **IW 思想**: 「Intervene in the world」を自分の半径 3km から実装する。屋号思想の身体化
- **収益**: IW 直営として売上を作る vehicle

---

## ターゲットと痛み

**ターゲット**: 東京都内（特に足立・北）の個人経営の飲食店・美容室・サロン

**拾う痛み**:
- 大手ポータルサイトの手数料が高くて利益が残らない
- SNS 運用 / 予約電話対応で本業の時間が削られる
- ホームページ作りたいけど何から手をつけたらいいか分からない
- 業者に頼むと高そうで相談できない

---

## 引き算の craft

「最大化」じゃなく「本来に戻す」方向で訴求。お客さんと向き合う時間、料理 / 髪に集中する時間を、お店に取り戻す。

専門用語は最小化。「最新の技術を駆使」「テクノロジー」「オーダーメイド」みたいな足し算の言葉は使わない。

## 4 Phase 設計

### Phase 0: 自分で全部試す（今ここ、〜2026-07 目処）

自分で GBP / 公式 LINE / Stripe / LP 一通り立ち上げて運用する。動線・痛みを memory に蓄積。**「無名新規事業者が地元で認知される過程」を当事者として観察する**。

### Phase 1: 商品・価格決定 + 発信

Phase 0 の痛み・実感をもとに「自分が払うならこの価格」を体感で決める。hook 商品の入り口設計。

### Phase 2: 顔見知り作り（提案じゃなく交流先行）

客として地元の個人店に通う。提案禁止、まず関係を作る。

### Phase 3: 最初の craft

顔見知りの中で「困ってる」とこぼした人に初提案。最初の 1 件は安く・丁寧に。
