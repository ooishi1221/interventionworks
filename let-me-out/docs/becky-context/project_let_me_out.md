# 放置恋姫 〜永久に続く覚醒の輪廻〜（内部コード "Let Me Out"）

ソシャゲ業界の **引き止め構造への風刺作品**。プレイヤーは「もうこのゲーム辞めたい」状態でスタート、引き止め演出を 5 段階突破して離脱する 15-20 分のゲーム。Anti-Gacha Game とは別軸の Intervention Works portfolio 候補。

## 発案の文脈

2026-05-03 GW Day 2 朝、ベッキー × 裕司の議論で発案。Anti-Gacha Game（前日 5/2 closure 発案、リセマラ純度 100%）と「別アプローチで業界風刺ゲーム作りたい」から始まり、3 案（"Let Me Out" / 公式生放送耐久ゲーム / Customer Service Hell）の中から **"Let Me Out"** を選択。30 分の議論で仕様確定まで進む。

## Core Insight

### 風刺対象 = 業界の「引き止め構造」

ソシャゲ業界が顧客に向ける引き止め圧の網羅：
- 連続ログインボーナス、未受取消滅警告（義務感）
- ギルド・フレンド通知（社会性）
- 期間限定・限定 SSR（損失回避）
- お詫び石・カムバック詫び（補償）
- アンインストールアンケート → 回答詫び石（最後の壁）

→ **辞めようとしても辞めさせてくれない**現代ソシャゲの構造を可視化する。

### コア構図（裕司の言語化）

> **ユーザー：ソシャゲを辞める / 運営：引き止める**
> このゲーム自身もまた、引き止めてくる。

業界の引き止め圧を網羅 + メタ構造で **批判する側も同じ構造に取り込まれる** ことを表現。

### "Let Me Out" の核（裕司の言語化、2026-05-03）

> **「中華のだるさ × 日本のキレ」**
> 引き止め圧（中華）で出口を塞ぎ、ガチャ演出のキレ（日本）で痛みを忘れさせる。
> **業界の悪い癖の両極を交配させる**フランケン構造。

中華放置 RPG の引き止め UI 美学 × 日本ガチャの SSR 確定光演出 = 業界全体への風刺（中華系 or 日本系どちらかに偏らず、海外プレイヤーにも刺さる）。

## ゲームデザイン

### 1 セッションの流れ（時系列）

#### Layer 0: 起動画面

> 「お疲れ様でした。`放置恋姫`はサービス開始から 3 年、あなたを 847 日お迎えしました。本日アンインストールをご検討いただき、誠にありがとうございます。最後に少しだけお時間いただけますか？」

「アプリを閉じる」ボタンを押すとプレイ開始。

#### Layer 1: 日常引き止め

- 「ログインボーナス受け取りますか？」→ 未受取消滅赤字警告
- 「7 日連続まであと 1 日です！」連続ボーナス更新

#### Layer 2: 人間関係引き止め

- 「ギルドメンバー *Tanaka* さんが ❤️ を送りました」
- 「フレンドの *Yuji* さんがログインしました（最終 6 ヶ月ぶり）」
- フェード長め、BGM しっとり

#### Layer 3: 機会損失引き止め

- 「【あと 23 時間】100 連無料ガチャ開催中」
- 「あなたが集めていた限定 SSR 復刻」
- タイムリミット常時点滅

#### Layer 4: 詫び引き止め

- 「【お知らせ】先週のメンテにご迷惑をおかけしました。お詫び石 3,000 個進呈」
- 受け取ると残高表示で**ガチャ画面に強制遷移**

#### Layer 5: アンケート引き止め

- 「アンインストール」→ 長文アンケート（10 問・選択式）
- 「ご回答ありがとうございました。お詫び石 5,000 個」
- 残高更新演出 → ガチャに戻る

#### 勝利

- 実際に閉じられた瞬間 → 「Congratulations. You are free.」

### 引き止めパターン・カタログ（実装単位）

| カテゴリ | パターン | 業界の symbolize |
|---|---|---|
| 義務感 | 連続ログイン途切れ警告 | 義務化されたエンタメ |
| 社会性 | フレンド・ギルド通知 | 人間関係の人質 |
| 損失回避 | 限定・期間 | 焦らせの定型 |
| 補償 | 詫び石・アンケ詫び | 引退タイミングを溶かす |
| サンクコスト | 「あなたの 847 日」 | 過去への固定 |
| ストア最適化 | 評価依頼ポップアップ | 退会時に星 5 を狙う厚顔 |

→ 各 Layer は独立モジュール、1 個ずつ実装してプレイテスト。

### Layer の順番と強度

**固定順序 + 細部ランダム**:
- Layer 1 → 2 → 3 → 4 → 5 の重さ登り坂は固定（起承転結）
- 各 Layer 内の引き止め文言は 10 個プールから 3 個抽出
- 配信で「あ、これ出た」共通言語 + 「自分のときは違ったw」二層化

### スコア設計

| 指標 | 値 |
|---|---|
| **離脱までの所要時間** | 短いほど勝ち |
| **食らった引き止め数** | 少ないほど勝ち |

| **罪悪感メーター** | "ギルドのみんなを見捨てる" を選ぶと加算 |

最終画面：
> 「あなたは 23 分 47 秒で自由になりました。詫び石 47,000 個はこの世界に置いていきます。」

### メタ構造（風刺の二重化）

**クリア直後 + 2 回目起動時の二重メタ**:

1. **クリア直後**: 「You are free」の直後、アプリ閉じようとすると "放置恋姫" 自身が「アンケートにご協力ください」と出す → 答えると詫び石（無価値）→ ホームに戻される
2. **2 回目起動時**: 「お帰りなさい！カムバックキャンペーン詫び石 10,000 個進呈」→ 業界の離脱者追跡 CRM を逆手に取る

→ 「**業界を風刺してるはずのこのゲームも、結局同じ手口でお前を引き止める**」自己言及的アイロニー。批判者を聖域にしない（Intervention Works DNA）。

### 学んだこと（地雷地図）

- **Unity 6.3 LTS の UI Toolkit + Sprite は地雷**: `<ui:Image>` 要素 + Resources.Load の組合せで `Invalid value for image texture Function` 警告が継続。Sprite 用の placeholder ⚠ が画面外で巨大表示される。実機リリース時は uGUI 推奨

- **Gemini に「トレース」指示が効く**: 放置少女スクショを参考画像として「これと同じ構図で別キャラ作って」と依頼すると、業界アプリ立ち絵が生成される（パロディ境界の管理は別途）

画面下部の JRPG 風メッセージウィンドウ（半透明黒 + 金縁 + KAGUYA-X 金プレート + ▼ 点滅インジケータ）。7 セリフを 5.5 秒ごとローテ：

### 多端末対応 3 連戦（Vercel 配布で発覚）

公開後すぐに知り合い配布 → **3 つの実機問題**が立て続けに出て、現場対応:

#### 1. Android Chrome でスワイプ斬りが効かない
- 真因: `touch-action` 厳格、スワイプがスクロールに奪われる
- 修正: `.home-screen { touch-action: none; -webkit-user-select: none; overscroll-behavior: none }`、モーダル系は `touch-action: pan-y` で上書き

#### 2. iOS / Android パフォーマンス重い
- 真因: `document.elementFromPoint()` を pointermove 毎に呼ぶ → Layout 強制再計算 + setState 連発で React 再 render
- 修正:
  - **sweep の rAF throttle**（同 frame 1 回まで）
  - **hit-fx 70ms 間引き**
  - **+N popup 上限 10 個**
  - **whack-badge の backdrop-filter 削除**（GPU 負荷の元凶、大量描画時）

裕司「だいぶ軽くなった」確認、爽快感戻った。

#### 3. Xperia 1-6（21:9 縦長）で画面中央に小さく + 黒帯
- 真因: `.phone-frame` の `max-width: 480 / aspect-ratio: 9/20 / max-height: 1066` で iPhone 比率に固定、`@media (max-width: 600px)` のリセットが Xperia の CSS 幅 > 600 で効かなかった
- 試行錯誤: `(max-width: 768px), (pointer: coarse)` → 雑判定、裕司「やっつけ仕事！！！」
- 最終解: **反転戦略 — デフォルトで全画面、デスクトップ（hover: hover + pointer: fine + landscape）でだけ iPhone 枠**
- これで全縦長スマホで自動全画面化、iPad もタッチデバイスなら全画面
